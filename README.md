## Usage

After installation, you can start using SoftMicro Drapes Server 2012. Here are some basic commands and functionalities:

- **Access the Dashboard**: Open your web browser and navigate to `http://localhost:8080` to access the dashboard.
- **Create a New Project**: Use the command line to create a new project with `drapes create project_name`.
- **View Logs**: Check server logs with `drapes logs`.
